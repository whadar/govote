# הפעם כולם יוצאים להצביע

הדמיה אינטראקטיבית: כמה קולות נוספים כשכל אחד מדבר עם חבר או שניים שעדיין בבית, בתל אביב, חיפה, מודיעין ורעננה. מתחת להדמיה יש מדריך קצר לשיחה עם חבר שעוד לא הצביע.

## הרצה

קובץ אחד, בלי תלויות ובלי בנייה. פותחים את `public/index.html` בדפדפן. באתר: [govote.day](https://govote.day).

קישור ישיר לעיר: `govote.day/#tlv`, `#haifa`, `#modiin` או `#raanana`.

## המודל

- כ 4,000 נקודות על סקיצה של העיר, כל אחת מייצגת כמה עשרות עד מאות בעלי זכות בחירה.
- לכל נקודה כ 8 חברים, כמעט כולם שכנים קרובים.
- נקודת הפתיחה: אחוז ההצבעה בעיר בבחירות 2022.
- כל מי שמצביע מדבר פעם אחת עם מספר החברים שנבחר מבין אלה שבבית. כל שיחה מצליחה בסיכוי שבהגדרות (ברירת מחדל 25%), ומי שהשתכנע מדבר עם החברים שלו.
- חלק מבעלי זכות הבחירה מחוץ להישג יד (ברירת מחדל 12%), והם קובעים את הגבול העליון.

זו הדמיה שממחישה מנגנון, לא תחזית.

## מקורות לנתוני הערים

- תל אביב יפו: עיריית תל אביב, תוצאות הבחירות לכנסת ה 25.
- חיפה: ynet, הבחירות במספרים 2022. מספר בעלי זכות הבחירה הוא הערכה.
- מודיעין ורעננה: netunim.co.il, תוצאות הבחירות לכנסת ה 25 לפי יישוב.
